# SIKOLAYA

A React + TypeScript + Vite starter project for the SIKOLAYA study website.

## Run locally or in StackBlitz

1. Import this ZIP into StackBlitz as a **React + TypeScript / Vite** project, or create a new Vite React TypeScript project and copy these files into it.
2. Wait for dependencies to install.
3. Run the project with `npm run dev` if StackBlitz does not start it automatically.

## Included in this prototype

- Responsive homepage with custom CSS illustrations
- Psychology (PmLE) subject overview
- CHRA subject overview
- Practice Center landing page
- About page
- Login and registration preview screens
- Working in-app navigation

## Important

This is a front-end prototype. Login and registration are intentionally disabled placeholders. Supabase authentication, database access, lesson content, quiz scoring, saved progress, and admin tools are **not connected yet**. Do not collect real student credentials with this prototype.
